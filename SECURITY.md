# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. **Do not open a public issue, pull request or discussion.**

- **Email:** gabriel@powvprotocol.com, with the subject line `SECURITY`.
- **Include:** the affected repository, file or component, the steps to reproduce, the impact you expect, and whether the issue is already public.
- **Never include** private keys, tokens, passwords or personal data. If a secret is involved, describe where you found it, not what it is.

We aim to acknowledge reports within 5 business days and to agree a disclosure timeline with the reporter.

## Scope

This policy covers the public repositories of the PoWV Protocol organization. Experimental and access-controlled work is handled under the same process.

## Current status

PoWV is a conceptual research program. Its repositories contain research, documentation and experimental code. They are not production systems. Cryptographic integrity does not establish metrological accuracy.
